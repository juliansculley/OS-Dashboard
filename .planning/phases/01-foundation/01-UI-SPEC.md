# Phase 1 — UI Design Contract

> Visual and interaction contract for the Foundation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 1 scope:** Navigation shell only — left sidebar, two placeholder pages (Home, Social), CSS token system, XSS sanitization layer. No real data, no skill trigger buttons, no interactive forms.

## Typography

All font sizes inherit the Obsidian interface font. Satoshi is loaded as a progressive enhancement — if offline, the fallback chain (`var(--font-interface, sans-serif)`) keeps the plugin functional.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Nav item labels, general text |
| Label / Heading | 12px | 600 (semibold) | 1.3 | Stat card labels, section sub-headers, section headers (uppercase + letter-spacing: 0.06–0.08em) |
| Display | 22px | 600 (semibold) | 1.2 | Page titles only (`claudeos-page-title`) |

**Logo text:** 14px, weight 600, uppercase, letter-spacing: 0.05em, color: `var(--cos-accent)`.

**Weight rule:** Two weights only — 400 (regular) and 600 (semibold). No other weights are used anywhere in Phase 1.

## Color

This plugin is theme-adaptive. The dominant and secondary surfaces are **not hardcoded** — they inherit from Obsidian's CSS variable system. Only the accent is a brand token.

| Role | Token | Fallback Value | Usage |
|------|-------|---------------|-------|
| Dominant (60%) | `var(--background-primary)` | Obsidian theme default | Main canvas background (`--cos-bg`) |
| Secondary (30%) | `var(--background-secondary)` | Obsidian theme default | Sidebar background, stat card background (`--cos-surface`) |
| Surface variant | `var(--background-secondary-alt, var(--background-secondary))` | Same as secondary | Nav item hover background (`--cos-surface-2`) |
| Accent (10%) | `#7c6af7` | — | See reserved list below |
| Accent hover | `#6857e0` | — | Accent element hover state only |
| Destructive | `var(--color-red, #e53e3e)` | `#e53e3e` | Error state background tint (10% opacity via `color-mix`) |
| Border | `var(--background-modifier-border)` | Obsidian theme default | All borders and dividers (`--cos-border`) |
| Text primary | `var(--text-normal)` | Obsidian theme default | All primary text (`--cos-text`) |
| Text muted | `var(--text-muted)` | Obsidian theme default | Secondary text, inactive nav labels (`--cos-muted`) |
| Text faint | `var(--text-faint)` | Obsidian theme default | Placeholder text, disabled states (`--cos-faint`) |

**Accent (`#7c6af7`) reserved exclusively for:**
1. Logo / wordmark text in the sidebar header
2. Active nav item text color
3. Active nav item background tint (`color-mix(in oklch, var(--cos-accent) 15%, transparent)`)
4. (Phase 2+) Primary action button background — not used in Phase 1

Accent is NOT used on: borders, body text, headings, placeholder content, section labels.

**Source:** `--cos-accent: #7c6af7` from archive spec §11, §16; confirmed in `DEFAULT_SETTINGS.accentColor` (archive spec §9).

## Interaction Contract

### Navigation

- Clicking a sidebar nav item sets `activePage` state in `App.tsx` via `onNavigate` callback.
- Page switch is **instant** (synchronous React state update) — no animation, no loading state, no full re-render of the sidebar.
- Active item styling: text color switches to `var(--cos-accent)`, background shows 15% accent tint, font-weight becomes 600.
- Inactive item styling: text color `var(--cos-muted)`, no background, font-weight 400.
- Hover styling: background `var(--cos-surface-2)`, text color `var(--cos-text)`, transition 150ms.

### Transitions

- Nav item background and color: `transition: background 150ms, color 150ms` — no other transitions in Phase 1.

### States to implement in Phase 1

| State | Where | Implementation |
|-------|-------|---------------|
| Active nav item | Sidebar | `.claudeos-nav-item.active` CSS class |
| Hover nav item | Sidebar | `.claudeos-nav-item:hover` CSS class |
| Placeholder page content | HomePage, SocialPage | Static heading only — no empty state component needed |

### States NOT in Phase 1 (deferred to Phase 2)

- Loading spinner (skill trigger buttons)
- Error state display (data fetch failure)
- Empty state (missing data files)
- Button disabled / loading states

## CSS Token Reference

Full token declarations for `styles.css`. Executor must use these exact tokens — do not introduce unlisted custom properties.

```css
.claudeos-dashboard {
  /* ── Brand tokens (Phase 1 only uses accent) ── */
  --cos-accent:        #7c6af7;
  --cos-accent-hover:  #6857e0;

  /* ── Layout tokens ── */
  --cos-sidebar-width: 200px;
  --cos-radius:        8px;

  /* ── Font token ── */
  --cos-font-display:  'Satoshi', var(--font-interface, sans-serif);

  /* ── Surface tokens — inherit from Obsidian theme ── */
  --cos-bg:         var(--background-primary);
  --cos-surface:    var(--background-secondary);
  --cos-surface-2:  var(--background-secondary-alt, var(--background-secondary));
  --cos-border:     var(--background-modifier-border);

  /* ── Text tokens — inherit from Obsidian theme ── */
  --cos-text:       var(--text-normal);
  --cos-muted:      var(--text-muted);
  --cos-faint:      var(--text-faint);

  /* ── Font mono (for future phases) ── */
  --cos-font-mono:  var(--font-monospace);
}
```

**Token discipline:** `--cos-*` is the only namespace used. No bare `--color-*` or `--spacing-*` declarations inside `.claudeos-dashboard`. Obsidian variables are referenced by their native names (e.g., `--background-primary`) only as values in `--cos-*` assignments.
